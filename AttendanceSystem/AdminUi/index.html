סקירה כללית

תמונת מצב של אירועים מסווגים. כל הנתונים להמחשה בלבד.

סביבת הדגמה — אין כאן חיבור למכשירים או מידע אישי.

חיבור בדיקה ל־API מקומי

למפתחים בלבד: הדבקת JWT קצר־מועד בזיכרון הדפדפן. אין שמירה באחסון מקומי ואין כניסה אוטומטית. רק API ב־localhost.
